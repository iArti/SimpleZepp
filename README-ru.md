# SimpleZepp

Форк [SimpleWear](https://github.com/SimpleAppProjects/SimpleWear) (автор Dave Antoine) для часов на
**Zepp OS** (Amazfit) вместо Wear OS. Управление Android-телефоном с часов.

[English version](README.md)

## Возможности

- **Переключатели:** Wi-Fi, Bluetooth, мобильные данные, геолокация, фонарик, «Не беспокоить», режим звонка
  (звук / вибрация / без звука), точка доступа, NFC, экономия батареи, блокировка экрана
- **Громкость** по потокам (медиа, звонок, разговор, будильник) и **яркость** (включая авто);
  кнопки Up/Down меняют значение
- **Запуск приложений** на телефоне с часов
- **Заряд телефона** на главном экране
- **Музыка:** управление тем, что играет на телефоне (Spotify, YouTube Music, любое приложение с медиасессией),
  перенесено из [Spotify Remote](https://github.com/iArti/zepp-better-spotify-remote): скринсейвер с обложкой
  (тап — пауза, двойной тап слева/справа — назад/вперёд), кольцо прогресса, лайк (если плеер его даёт),
  барабан очереди, свои действия плеера (перемешивание, повтор, радио…, свайп вверх), выбор плеера, громкость.
  Цвета берутся из иконки приложения-плеера. Ладонь на экране — пауза
- **Shortcut-карточка:** уровень сигнала Wi-Fi и сотовой сети, режим звонка и заряд; тап или Select открывает приложение

Управление звонками из SimpleWear убрано: в Zepp OS это уже есть.

## Как это устроено

```
Приложение на часах (JS) ⇄ Zepp на телефоне (app-side JS) ⇄ HTTP 127.0.0.1:47821 ⇄ Android-приложение SimpleZepp
```

- App-side в Zepp умеет только HTTP-запросы, поэтому Android-приложение поднимает маленький HTTP-сервер
  на **loopback** (`ZeppBridgeService`, foreground-сервис). Сообщения часы → телефон — те же пути и JSON, что у
  Wear OS Data Layer в SimpleWear, и обрабатываются неизменённой логикой SimpleWear (`WearMessageHandler`).
  Сообщения телефон → часы копятся в очереди и забираются long poll'ом.
- `fetch` в Zepp обрывает запрос через ~10 с, поэтому long poll отвечает не позже чем через 8 с.
- **Привязка:** при первом подключении на телефоне появляется уведомление *Allow / Deny*, после чего app-side
  хранит токен. До loopback-порта может достучаться любое приложение на телефоне, поэтому без токена запросы
  не принимаются.
- **Встроенный Helper.** В оригинале есть отдельное приложение *SimpleWear Helper* с `targetSdk 28` для
  переключателей, которые новые Android запрещают (Wi-Fi, Bluetooth, …). Форк ставится вручную, поэтому всё
  приложение таргетит SDK 28, а код действий Helper (`wearsettings/…/actions`, root и Shizuku) встроен.
- Уровни сигнала (`/status/signal`) — добавление форка; SimpleWear передаёт только вкл/выкл.
- Firebase и проверка обновлений через Google Play убраны.

Код: `mobile/…/zepp/` (мост), `zepp/` (приложение для часов, app-side, карточка).

## Ограничения

- **Только Android.** На iOS такое невозможно.
- Приложение на телефоне должно жить в фоне. Некоторые прошивки замораживают фоновые приложения даже с
  foreground-сервисом (замечено на Honor / MagicOS) — разрешите работу в фоне вручную (см. ниже).
- Статус обновляется вживую, только пока на экране часов открыто приложение или карточка; в остальное время
  карточка показывает последнее известное состояние.
- Мобильные данные, точка доступа и ещё кое-что требуют Shizuku или root (как и в оригинале).
- `targetSdk 28`: Android может предупреждать, что приложение создано для старой версии. Не для Google Play.
- На часах пока нет экранов для действий по таймеру и жестов (телефонная часть их поддерживает).
- Интерфейс на часах пока только на русском.
- Проверено на Amazfit Active 3 Premium (Zepp OS 6, круглый 466×466) и Honor Magic V2 на Android 16.

## Установка

### 1. Приложение для телефона

**Скачать:** [SimpleZepp-0.1.1.apk](https://github.com/iArti/SimpleZepp/releases/download/v0.1.1/SimpleZepp-0.1.1.apk)
из [Releases](https://github.com/iArti/SimpleZepp/releases/latest) (подписан ключом автора) и установить —
или собрать самому. APK с другой подписью поверх не встанет: сначала удалите установленный.

Для сборки нужны JDK 17+ (например, из комплекта Android Studio) и Android SDK.

```bash
./gradlew :mobile:assembleDebug
adb install -r mobile/build/outputs/apk/debug/mobile-debug.apk
```

Без `keystore/keystore.properties` APK подписывается вашим debug-ключом (см. `signing.gradle`).

Откройте **SimpleZepp** на телефоне и выдайте нужные разрешения на экране разрешений. Кроме того:

- **Уведомления** должны быть разрешены: привязка подтверждается через уведомление.
- **Доступ к уведомлениям** нужен для управления музыкой (только так Android показывает медиасессии плееров).
- Отключите оптимизацию батареи для приложения. На Honor / Huawei: *Батарея → Запуск приложений → SimpleZepp →
  вручную*, включите все три переключателя.
- Для мобильных данных, точки доступа и т. п. выдайте в приложении доступ [Shizuku](https://shizuku.rikka.app/) или:
  ```bash
  adb shell pm grant dev.iarti.simplewear android.permission.WRITE_SECURE_SETTINGS
  ```

### 2. Приложение для часов

Нужны Node.js и [zeus-cli](https://docs.zepp.com/docs/guides/tools/cli/), в приложении Zepp включён
*режим разработчика* (Профиль → Настройки → О программе → 7 раз нажать на значок Zepp).

```bash
cd zepp
npm install
npx zeus login
npx zeus preview
```

Выберите модель часов и отсканируйте QR-код в Zepp → Профиль → Developer Mode → Scan.

`appId` 1145144 зарегистрирован на аккаунт разработчика автора. Если `zeus preview` его не принимает, создайте
приложение в [консоли разработчика Zepp](https://console.zepp.com/) и пропишите его id в `zepp/app.json` и
`APP_ID` в `zepp/app-widget/index.js`.

### 3. Привязка

Откройте SimpleZepp на часах, нажмите на строку под батареей («Нажмите, чтобы привязать») и нажмите **Allow**
в уведомлении на телефоне. Карточка добавляется как любая другая в настройках shortcut-карточек часов.

Иконки: `python zepp/tools/make_icons.py` (нужен ImageMagick) рисует их из векторных drawable SimpleWear.
